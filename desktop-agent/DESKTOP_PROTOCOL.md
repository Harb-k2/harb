# بروتوكول عميل Harb المحلي

## مسار الاقتران

ينشئ المالك رمز اقتران من لوحة Harb صالحاً لمدة عشر دقائق ولمرة واحدة. يرسل العميل إلى مسار Harb العام اسم الجهاز، والنظام (`windows` أو `kali_linux`)، والرمز. عند نجاح الاقتران يحفظ العميل معرفه ورمز الجلسة في ملف إعدادات محلي؛ يشفر رمز الجلسة بواسطة مخزن أسرار نظام التشغيل ولا يظهر في الواجهة أو سجل التدقيق.

يرسل العميل نبضة كل 45 ثانية للحصول على الحالة والنطاقات الحالية. لا تعني النبضة السماح بعملية: النطاقات لا تمنح التشغيل الذاتي، ويظل تأكيد المستخدم المحلي وقانون المالك والبوابات التنفيذية مطلوبة.

تعيد النبضة أيضاً قانون المالك المختصر وطلبات الموافقة المحلية المعلقة الخاصة بذلك العميل. يطبق العميل القواعد المتزامنة قبل معاينة ملف وقبل **إنشاء** أي طلب تشغيل برنامج أو أمر أو تعديل ملف؛ ويمنع طلباً مكرراً من النوع نفسه ما دامت تذكرة ذلك العميل معلقة. ثم يعيد الخادم فحص نطاق العميل وقانون المالك قبل إنشاء التذكرة. تُحوَّل هذه الأنواع إلى **طلب موافقة فقط** ولا تنفذ في الإصدار الأول. لا يستطيع رمز العميل اعتماد أو رفض التذكرة؛ يفتح زر المراجعة لوحة Harb، ويُحسم الطلب حصراً من جلسة مالك مصادق عليها في قائمة الموافقات العامة.

| العملية المحلية | نطاق Harb المطلوب | حالة الإصدار الأول |
| --- | --- | --- |
| اختيار ملف ومعاينة أول 64 كيلوبايت | `read_files` + اختيار المستخدم | متاح |
| تشغيل برنامج | `run_programs` + فحص محلي وخادمي + موافقة مالك | مسجل للتدقيق؛ لا تنفيذ تلقائي |
| تشغيل أمر | `run_commands` + فحص محلي وخادمي + موافقة مالك | مسجل للتدقيق؛ لا تنفيذ تلقائي |
| تعديل ملف | `modify_files` + فحص محلي وخادمي + موافقة مالك | مسجل للتدقيق؛ لا تنفيذ تلقائي |

تتضمن الواجهة زر **فحص بوابة التنفيذ**. يمر الفحص في الأنواع الثلاثة عبر النطاق وقانون المالك وتذكرة اعتماد صادرة وموقعة من الخادم. يعيد العميل التذكرة إلى Harb للتحقق من توقيع الخادم، وهوية العميل، ونوع الإجراء، وحالة الموافقة، وانتهاء الصلاحية قبل السماح بالانتقال إلى حالة البوابة التالية. من دون تذكرة معتمدة يرجع حالة انتظار موافقة المالك، ومع تذكرة صحيحة يرجع حالة `executor_disabled`. لا تستدعي هذه البوابة `shell` أو `child_process` أو أي واجهة نظام تشغيل، وتكتب حالة الحجب فقط في سجل التدقيق المحلي والوصفـي.

## التدقيق وحماية البيانات

يسجل العميل محلياً الاقتران والنبض وعمليات المعاينة والحجب. يزامن إلى المنصة فقط معرف الحدث، واسم الملف المختار وحجمه عند المعاينة، أو سبب الحجب؛ لا يرسل المحتوى المحلي أو المسار الكامل أو رمز الجلسة. لا يحمل طلب الموافقة أمراً خاماً أو مساراً كاملاً؛ بل ملخصاً محدوداً يقدمه المستخدم. ويُحظر أي تنفيذ لا يمر عبر نطاق مفعل وتأكيد محلي وقانون المالك وموافقة من جلسة المالك.

يسجل الخادم نبضاً وصفياً واحداً كل خمس دقائق كحد أقصى لكل عميل لتجنب تضخيم سجل التدقيق، ولا يحتوي الحدث على أسرار أو مسارات أو محتوى محلي.
