# Harb Desktop Agent

عميل Electron متعدد المنصات لويندوز وكالي لينكس. يستخدم رمز اقتران صادر من لوحة Harb، ثم يحفظ معرف العميل ورمز الجلسة في مساحة بيانات المستخدم المحلي بصلاحيات ملفات مقيدة. يسحب النطاقات عبر نبضة دورية، ولا يمنح الاقتران أو النبض أي صلاحيات ذاتية.

## السلوك الحالي

يدعم الإصدار الأول الاقتران، النبض، عرض النطاقات، سجل تدقيق محلي، ومعاينة ملف اختاره المستخدم بعد توفر نطاق `read_files`. قبل تسجيل أي طلب تشغيل برنامج أو أمر أو تعديل ملف، يفحص العميل نطاقه وقانون المالك المتزامن محلياً، ثم يعيد خادم Harb الفحص قبل إنشاء التذكرة. لا يشغل العميل برنامجاً أو أمراً ولا يعدل ملفاً تلقائياً؛ الحسم يتم فقط من جلسة المالك المصادق عليها في لوحة Harb، ولا يملك رمز العميل اعتماد الطلب أو رفضه.

## التشغيل والتغليف

```bash
pnpm install
pnpm dev
pnpm test
pnpm package:linux
pnpm package:win
```

## التثبيت والاستخدام

على Kali Linux استخدم ملف `.deb` عبر `sudo apt install ./harb-desktop-agent_0.1.0_amd64.deb`، أو امنح ملف AppImage صلاحية التنفيذ ثم شغله. على Windows فك ضغط حزمة `Harb-Desktop-0.1.0-win-x64.zip` وشغل `Harb Desktop.exe`. بعد تشغيل العميل، أنشئ رمز الاقتران من لوحة Harb وأدخل رابط المنصة المنشورة واسم الجهاز والرمز. تظل صلاحيات الجهاز فارغة حتى يفعّلها المالك من اللوحة.

> **تنبيه توزيع:** الحزم المتولدة في بيئة التطوير غير موقعة بشهادة توزيع خاصة بالمالك. يبني Windows بأفضل موثوقية على عامل Windows أصلي، بينما تبنى حزم Kali/Linux على عامل Linux أصلي. قبل التوزيع المؤسسي، أضف شهادة توقيع مناسبة لكل نظام واحفظ أسرار التوقيع في نظام أسرار خاص بخط البناء.
