# مراجعة حوكمة مصادر البيانات الواردة لــ Harb

**الحالة:** مكتمل للترشيح الوصفي فقط. لا تمثل هذه الوثيقة موافقة على تنزيل بيانات أو تدريب نموذج أو ضبط دقيق. يبقى Harb في وضع `ready_models_only`، ويقتصر أي إدراج في السجل على **مرجع معرفة** أو **تقييم دفاعي فقط** مع مراجعة حقوق لازمة.

## قرار الحوكمة

لا تشكل القائمة الواردة في الملف المرفق «بيانات تدريب» بحد ذاتها. لذلك لا تنقل المنصة أي ملفات أو عينات أو PCAP أو صور أو كود، ولا تنشئ فهرسة تلقائية، ولا ترسل محتوى إلى نموذج، ولا تبدأ تدريباً أو تخصيصاً. تسجل مراجع الشبكات الستة التي أوردت روابط رسمية باسمها، مع الحالة `rights_review_required` والنطاق `evaluation_only`.

| الفئة | المصدر | القرار داخل Harb | سبب القرار |
|---|---|---|---|
| شبكات سيبرانية | CIC-IDS2017 | مرجع تقييم دفاعي فقط | الصفحة تتيحه للباحثين مع الاستشهاد، ولا تعرض تصريح تدريب تجاري عام. [1] |
| شبكات سيبرانية | CSE-CIC-IDS2018 | مرجع تقييم دفاعي فقط | يسمح المصدر بإعادة النشر مع الإسناد، لكنه لا يعفي من مراجعة الحقوق والخصوصية للتدريب. [2] |
| شبكات سيبرانية | CIC-DDoS2019 | مرجع تقييم دفاعي فقط | يسمح بإعادة التوزيع مع الاستشهاد؛ لا يحول هذا الشرط المصدر إلى موافقة لتدريب نموذج عام. [3] |
| شبكات سيبرانية | UNSW-NB15 | مرجع تقييم دفاعي فقط | الاستخدام الأكاديمي مسموح، أما التجاري فيتطلب اتفاقاً مع المؤلفين. [4] |
| شبكات سيبرانية | TON_IoT | مرجع تقييم دفاعي فقط | الاستخدام التجاري مشروط بسؤال المؤلف؛ وقد يتضمن سجلات شبكات وأنظمة وقياسات. [5] |
| شبكات سيبرانية | BoT-IoT | مرجع تقييم دفاعي فقط | الاستخدام الأكاديمي مسموح، والتجاري يتطلب اتفاقاً؛ وتحتوي البيانات سيناريوهات بوتنت ومسح وتسريب. [6] |

## مصادر لا تسجل تلقائياً

مصادر الكود والرؤية وردت في الملف من دون روابط رسمية كاملة. لذلك تظل بحالة **ينقص رابط المصدر أو إثبات الحقوق** ولا تظهر كمصادر يمكن تسجيلها. حتى مع تقديم الرابط، تخضع كل مجموعة لمراجعة مستقلة للمصدر والترخيص والخصوصية وفصل التقييم عن أي بيانات تطوير مستقبلية.

| مجموعة المرشحين | ملاحظة حوكمة رئيسية |
|---|---|
| The Stack v1/v2 وStarCoderData | تتطلب The Stack v2 قبول الشروط، واتفاقاً للتنزيل الكثيف، والالتزام بتراخيص المصدر الأصلية وتحديثات الحذف؛ قد تضم أيضاً معلومات حساسة منشورة علناً. [7] |
| CodeSearchNet وBigCodeBench وHumanEvalPack وCommitPackFT وOctoPack | لا يكفي ترخيص مستودع الأداة وحده لاعتبار كل الكود والبيانات صالحاً للتدريب؛ يلزم رابط بطاقة البيانات والترخيص وبراهين المصدر لكل مرشح. يجري التعامل معها كبوابات تقييم مرشحة فقط. [8] |
| COCO وImageNet وLAION-5B | يحتاج كل مصدر شروطاً مستقلة. ImageNet مقيد بالبحث والتعليم غير التجاري، وLAION يصف نفسه كفهرس URL ونصوص بديلة لا كمخزن لصور مرخصة؛ لذا لا يجوز إعادة بناء المحتوى أو استعماله تجارياً افتراضاً. [9] [10] |

## بوابات قبل أي تغيير مستقبلي للوضع

أي طلب لاحق لتغيير وضع النماذج الجاهزة إلى تدريب أو ضبط دقيق يحتاج، قبل أي تنزيل، موافقة المالك المكتوبة، حقاً أو ترخيصاً موثقاً للاستعمال المقصود، فحص أسرار وبيانات شخصية ومحتوى ضار، فصل بيانات التدريب والتحقق والاختبار، وخطة حوسبة خارج بيئة خدمة الويب. لا يغطي هذا السجل أي تشغيل للهجمات أو إعادة إنتاجها؛ وتبقى مصادر الشبكات مخصصة للتقييم الدفاعي المنضبط فقط.
