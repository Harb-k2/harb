# سجل مراجع Harb العامة

## قرار الاستخدام

تستخدم هذه المصادر أولاً في **التقييم، الاسترجاع المقيد، وبناء حالات اختبار مرجعية**. لا يعني ظهورها هنا إذناً تلقائياً لنسخ محتواها كاملاً إلى بيانات ضبط دقيق؛ يلزم حفظ نسخة من الترخيص، ونسبة المصدر، ومراجعة قانونية داخل المؤسسة عند الجمع واسع النطاق أو الاستخدام التجاري أو إعادة التوزيع.

| المصدر | الاستخدام المقترح | وضع الحقوق | قرار Harb الحالي |
| --- | --- | --- | --- |
| MITRE ATT&CK STIX | تعيين المعرفة، تقييم الاسترجاع، وبناء حقول منظمة | ترخيص MITRE غير حصري وخالٍ من الإتاوة للبحث والتطوير والاستخدام التجاري بشرط إعادة بيان حقوق MITRE والترخيص في النسخ | مرشح للاستخدام المحدود بعد حفظ إشعار الحقوق والنسخة المرجعية [1] |
| MITRE CWE | تقييم تصنيف نقاط الضعف واستخراج الحقول المنظمة | ترخيص MITRE غير حصري وخالٍ من الإتاوة للبحث والتطوير والاستخدام التجاري بشرط إعادة إشعار الحقوق والترخيص | مرشح محدود بعد حفظ إشعار الحقوق ومراجعة المحتوى [5] |
| MITRE CAPEC | تقييم فهم أنماط الهجوم على مستوى المعرفة والتصنيف | ترخيص MITRE غير حصري وخالٍ من الإتاوة للبحث والتطوير والاستخدام التجاري بشرط إعادة إشعار الحقوق والترخيص | مرجع تصنيفي محدود؛ لا يستخدم لإنشاء تعليمات تشغيلية [6] |
| OWASP WSTG | تقييم فهم منهجيات اختبار الويب ومراجعها | CC BY-SA 4.0؛ يلزم النسب والمشاركة بالمثل عند انطباق الترخيص | تقييم أو اقتباسات محدودة مع نسب واضح؛ لا إدخال جماعي قبل مراجعة آثار المشاركة بالمثل [2] |
| OWASP ASVS | تقييم فهم متطلبات التحقق من أمن التطبيقات واستخراج المتطلبات المنظمة | CC BY-SA 4.0؛ ينشر المعيار أيضاً صيغ CSV وJSON | استخدام محدود مع نسب وإصدار محدد؛ لا إدخال جماعي قبل مراجعة آثار المشاركة بالمثل [7] |
| FIRST CVSS | تقييم فهم شدة الثغرات وتمثيل درجاتها المنظمة | توفر FIRST مواصفات وأدلة وإرشادات تطبيق لـ CVSS؛ يلزم مراجعة منفصلة لشروط النسخ والتوزيع | مرجع تقييمي فقط إلى حين اكتمال مراجعة الحقوق [8] |
| NIST CSF 2.0 | تقييم حوكمة المخاطر وتصنيف ممارسات الأمن المؤسسية | ينشر NIST الإطار ووثائقه ومراجعه الرسمية؛ يلزم تثبيت حقوق إعادة الاستخدام في سياق المؤسسة | مرجع تقييمي فقط إلى حين اكتمال مراجعة الحقوق [9] |
| NVD CVE/CPE | تقييم استخراج الحقول والتحديثات المنظمة | يوفر واجهات وملفات JSON رسمية؛ صفحة البيانات توصي بـ API 2.0 للتحديث | استخدام مرجعي/تقييمي فقط إلى حين تثبيت حقوق إعادة الاستخدام وسياق النشر [3] |
| CISA KEV | تقييم أولويات إدارة الثغرات وسلامة التوصيات | شروط الموقع تحكم الوصول والاستخدام ويمكن تغييرها | استخدام مرجعي محدود فقط؛ لا نسخ واسع أو تدريب قبل مراجعة حقوق المؤسسة [4] |

## ضوابط الجمع

لا يجمع Harb حالياً أي محتوى تلقائياً من هذه المصادر لأغراض التدريب. عند اعتماد مصدر، يسجل المالك الإصدار أو التاريخ، رابط الأصل، شروط الحقوق، طريقة النسبة، ومكان التخزين. يمر كل سجل بعد ذلك عبر `training:validate` قبل وضعه في تقسيم تدريب أو تحقق أو اختبار.
